## 4. Known gaps left open deliberately

1. **`calm_editor.py` passes no retrieval context** (`EasyEdit/easyeditor/editors/calm_editor.py`, `decide(..., retrieval_context=None)`). Fixing it changes a teammate-owned file and invalidates the team's 5K run, so it is filed as W6 finding B1 and as a recommendation in `docs/w4_gate_ablation_report.md` §3.5, not applied.
2. **No hypernetwork checkpoint for the ablation** (`hparams/CALM/gpt2-xl.yaml`: `hypernet_ckpt: null`). Consequence: the parametric channel cannot rewrite, and every retention number in W4 is side-memory retention. Adding a checkpoint would change the W4 budget beyond what W4 promised, so it is documented (`docs/w4_immediate_rewrite_diagnosis.md` §5) rather than trained.
3. **Two interface blueprints** for `ConflictGate` (W1 `calm/calm_editor.py` uses `decide(EditRequest, memory_snapshot)`; the shipped editor uses `decide(subject, relation, ...)`). Filed as W6 finding B2. The ablation works around it by importing `Decision`/`EditRecord` by absolute path from the owner's module.
4. **`pre-training-conflict` gold action** is derived from the label mapping, not human-labelled, and disagrees with what the arms actually do (no arm rejects). Recorded in §3.3.1 as a limitation of the label scheme, not silently corrected.
